Accessibility reference

Accessible browser uploads for event guests

Event upload pages serve a broad, temporary audience. Guests may be using an unfamiliar phone, a screen reader, larger text, reduced motion, or one hand in a crowded venue. The upload path should work without requiring prior product knowledge.

Interaction essentials

  • Associate every file input and text field with a persistent label.
  • Keep the primary action reachable by keyboard and visible at large text sizes.
  • Announce validation, progress, and completion changes to assistive technology.
  • Do not rely on color alone to communicate upload or moderation status.
  • Preserve focus when an item changes from transferring to complete.

Media-specific details

File-size and format limits should be visible before selection. Image previews need meaningful controls even when the image itself has no useful alternative description yet. Audio and video contributions should expose duration and a clear way to remove or replace the selected item before submission.

Error recovery is part of accessibility. Use specific messages, retain the selected file when retrying is possible, and avoid time-limited dialogs that disappear before a guest can understand them.

These principles inform the no-install contribution path on the Gathmo event media platform.
