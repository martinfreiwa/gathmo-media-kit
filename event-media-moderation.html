Operations reference

A moderation workflow for guest-created event media

Guest uploads and public display are separate decisions. An event can accept a contribution successfully while holding it for host review before it appears in an album or live wall. Treating those states independently prevents guests from retrying an upload simply because it is not visible yet.

Useful moderation states

  • Received: the original file and contribution metadata are stored.
  • Pending: the item is waiting for a host or moderator decision.
  • Approved: the item may appear in the intended event surface.
  • Hidden: the item remains retained according to policy but is not shown.
  • Removed: the item has entered a documented deletion workflow.

Moderators need enough context to make a decision: media preview, submission time, event, contribution type, and the current visibility state. Batch actions are useful during busy events, but every state change should remain reversible until a deliberate deletion step.

Live-display safeguards

A live wall should consume only approved items. If moderation falls behind, the display can rotate through already approved media rather than showing an unreviewed queue. Hosts should also be able to pause the display independently from guest uploads.

Gathmo applies this separation to event contribution and presentation. See the Gathmo corporate event workflow for the product context.
