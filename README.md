# Gathmo Media Kit

Official lightweight media kit for Gathmo, a QR-based event media platform for collecting guest photos, videos, and voice messages without requiring guests to install an app.

Website: <https://gathmo.com/>

## Product Summary

Gathmo helps hosts, couples, event teams, venues, and agencies collect event media in one private album. Guests scan a QR code and upload photos, short videos, and voice messages directly in the browser. Hosts can moderate, download, archive, and optionally show contributions on a live photo wall.
